Bacapedia
Sistem Manajemen Perpustakaan Digital menggunakan CodeIgniter 4.

Fitur
Login & Register
JWT Authentication
Role Admin dan Anggota
CRUD Kategori
CRUD Buku
Peminjaman Buku
Pengembalian Buku
Perhitungan Denda Otomatis
Riwayat Peminjaman
Dashboard Web
Teknologi
PHP 8
CodeIgniter 4
MySQL
Bootstrap 5
JWT (firebase/php-jwt)
Instalasi
git clone https://github.com/USERNAME/bacapedia.git
cd bacapedia
composer install
php spark migrate
php spark db:seed DatabaseSeeder
php spark serve
Akses aplikasi:

http://localhost:8080
